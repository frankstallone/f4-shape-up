# How-To: Use Hill Charts for Status

## Objective

Report status by certainty and momentum instead of percent-complete estimates.

## Model

- Uphill: problem-solving, unknown path
- Downhill: implementation path known, execution remaining

## Update routine

1. Define scopes for the project.
2. Place each scope uphill or downhill.
3. Add one sentence per scope: what changed since last update.
4. Flag blocked scopes explicitly.
5. Update at a steady cadence (for example twice weekly).

## Prompts for updates

- What uncertainty was resolved?
- What changed the implementation path?
- What is blocked and by what?
- What cut might be needed?

## Anti-patterns

- translating hill position into fake percentages
- moving downhill without resolved uncertainty
- hiding unknowns to look on track
