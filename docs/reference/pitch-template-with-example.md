## Example (condensed)

Problem:
Users cannot quickly see open scheduling slots from remote locations.

Appetite:
Six weeks.

Solution:
Add a lightweight grid-based availability view focused on open slots, not full calendar parity.

Rabbit holes:
- recurring event complexity
- drag-and-drop behavior

No-gos:
- no recurring event editor
- no category color system
- no full month/week/day mode switching

## Acceptance criteria

- core user task is achievable end-to-end
- out-of-scope boundaries are explicit
- major unknowns are patched or cut
