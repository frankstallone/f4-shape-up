# Reference: Betting Table Checklist

## Inputs required

- shaped pitches only
- available team capacity for next cycle
- current strategic priorities

## Evaluation checklist

- problem is meaningful now
- appetite matches value
- solution is understandable
- rabbit holes are patched or bounded
- right team is available

## Output checklist

- selected bets
- assigned teams
- explicit non-bets
- kickoff communication plan

## Constraints

- do not over-allocate teams
- avoid implicit backlog promises
- preserve uninterrupted build windows
