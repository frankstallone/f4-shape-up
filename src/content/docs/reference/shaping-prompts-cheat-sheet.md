## Session kickoff

- `use your shaping skill to capture the requirements and tease apart the key parts of the solution A`
- `create shaping.md and start with Problem/Outcome, requirements, and Shape A`

## Fit checks

- `show me R x A`
- `show me A x R`
- `show me R x [selected shape letter]`
- `re-run fit check after these requirement updates`

## Shape exploration

- `create an alternative shape B for the same requirements`
- `compare A and B using a fit check`
- `extract any implicit requirements that appeared during comparison`

## Spikes

- `please spike A2`
- `create this spike in a separate file`
- `update shaping doc and fit check with spike findings`

## Breadboarding and slicing

- `let's breadboard A`
- `let's slice it`
- `ensure each slice has demo criteria`

## Build and validation

- `make an implementation plan for V1 and include how you will test it`
- `run the app and verify V1 yourself before moving to V2`
- `test scenarios like add/remove locale and date changes; report failures first`

## Document consistency prompts

- `update Big Picture, shaping doc, and slices doc to reflect these changes`
- `check for drift between selected-shape fit check and slice plans`
