## Layer Cake

Work can be stacked in clear vertical layers where each layer adds value independently.

## Iceberg

Visible feature appears small but hidden technical depth is large.

## Chowder

Many small mixed tasks with weak structure; requires re-grouping before execution.

## Pattern usage

- Use Layer Cake when sequencing delivery slices.
- Treat Iceberg scopes as early risk targets.
- Refactor Chowder into meaningful scopes before committing.

## Scope quality checks

- each scope maps to a user-visible outcome or concrete technical boundary
- dependencies between scopes are explicit
- unknowns are concentrated, not scattered
