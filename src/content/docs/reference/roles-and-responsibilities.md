## Shaper

- frames the problem
- sets appetite
- outlines solution boundaries
- writes pitches

## Betting Table

- evaluates shaped pitches
- commits teams to bets
- protects focus during cycle

## Build Team (designer + programmers)

- discovers tasks from the pitch
- maps scopes and integrates slices
- decides scope cuts to ship on time

## Stakeholders

- provide context and feedback
- avoid interrupting active cycle execution
