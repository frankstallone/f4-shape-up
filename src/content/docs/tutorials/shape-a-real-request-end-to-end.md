## Scenario

A customer asks for "better scheduling". The request is broad and potentially expensive.

## Goal

Produce a bet-ready pitch in one session.

## Step 1: Narrow the problem

Interview one concrete workflow. Capture exactly where current behavior breaks.

Output:
- one sentence problem statement
- one target user outcome

## Step 2: Set appetite

Choose six weeks or small batch before designing.

Output:
- appetite decision with rationale

## Step 3: Breadboard the flow

Map places, affordances, and connections for the primary path.

Output:
- one-page breadboard

## Step 4: Patch rabbit holes

List top unknowns and patch with decisions, cuts, or no-gos.

Output:
- risk table with patch decisions

## Step 5: Write the pitch

Fill the template:
- problem
- appetite
- solution
- rabbit holes
- no-gos

## Step 6: Betting-ready review

Check:
- bounded scope
- explicit boundaries
- no unresolved critical unknowns

If all pass, move to betting table.
