## Objective

Choose projects for the next cycle without building a backlog commitment.

## Participants

- Decision-makers (founder/executive/product leadership)
- Optional shapers for clarification

## Procedure

1. Gather all shaped [pitches](/reference/glossary/#pitch).
2. Review each pitch quickly: problem, [appetite](/reference/glossary/#appetite), risk.
3. Decide against current product context and strategic timing.
4. Match [bets](/reference/glossary/#bet) to available teams.
5. Publish selected bets and explicit non-bets.

## Rules

- Bet on bounded pitches only.
- Do not assign unshaped work.
- Do not overbook teams.
- Preserve uninterrupted six-week execution.

## Output

- List of bets for cycle N
- Team assignments
- Deferred ideas (not backlog commitments)
