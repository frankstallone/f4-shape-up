## Objective

Ship a shaped project in six weeks.

## Procedure

1. Kick-off from the pitch.
2. Team maps scopes (not task tickets from managers).
3. Build one integrated vertical slice early.
4. Use hill-chart style status: uphill (figuring out), downhill (known path).
5. Cut scope when needed to protect shipment.
6. Ship by week 6; move leftovers back to shaping if needed.

## Anti-Patterns

- daily status micromanagement
- estimate-driven re-planning every few days
- late integration
- extending deadline by default
