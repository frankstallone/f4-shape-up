description: "Explanation: Fixed Time, Variable Scope"
---
Shape Up treats time as a hard constraint and scope as the tuning lever.

This changes behavior:

- teams prioritize the core path early
- trade-offs happen continuously, not only at deadline panic
- shipping discipline improves because extension is not the default

The model does not reduce ambition. It forces clearer decisions about what matters most in the current cycle.
